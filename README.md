# Donut Othello

Othello on a rectangle-plus-ring board (448 squares). Companion to the book
"Toward a Million Lines II — Building Othello for Windows and Android".
書籍『Toward a Million Lines II』の付録の、ドーナツ形の盤のオセロです。

The files are in **[Releases](../../releases)**, not in this repository.
ファイルは、このリポジトリではなく **Releases** に置いてあります。

- `donut.zip` — 日本語版 / Japanese edition
- `donut-en.zip` — English edition

Each ZIP contains the design documents, the Kotlin and Flutter source, and a prebuilt
Windows EXE and Android APK. The plain (non-donut) Othello is at
https://github.com/skogita/Othello-Game
